# Abdulrahman Muhammed Oglu — ملف اللاعب

موقع تعريفي للاعب يتضمن السيرة والصور والفيديو، مبني على React وNode.js/Express مع تبعيات رفع وسائط وMySQL.

## التشغيل والتطوير

`npm run dev` للتطوير و`npm run build` للبناء. يجب إعداد خدمات الخادم قبل الإنتاج.

## ملاحظات

يوثق هذا الملف البنية الموجودة، ولا يثبت اكتمال جميع الوظائف أو نجاح النشر. لا ترفع أسرار البيئة أو بيانات الإنتاج إلى GitHub.
